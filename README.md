# Tavoli

Social di confronto a tavoli. Next.js 15 + Supabase (progetto "tavoli", Francoforte).

## Avvio in locale
npm install
npm run dev

Le chiavi Supabase pubbliche sono già nel codice (lib/supabase.js); su Vercel si possono
sovrascrivere con NEXT_PUBLIC_SUPABASE_URL e NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY.

## Pubblicazione
Importa il repository su Vercel (Add New > Project): framework Next.js, nessuna impostazione extra.
